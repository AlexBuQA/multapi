# Логи сравнения агентов (блок 6.2)

Сюда пишет `python scripts/compare_agents.py`: по файлу на прогон, `NN_<задача>_<агент>.json`, где агент —
`naive` (блок 6.1, baseline) или `react` (блок 6.2), и сводку `summary.json`.

| NN | Задача | Тип |
|---|---|---|
| 01 | `simple_kb` — лимит API на тарифе «Команда» | простая |
| 02 | `simple_time` — который час в Екатеринбурге | простая |
| 03 | `compose_kb_send` — срок письма об автопродлении → сообщение в чат 12345 | средняя |
| 04 | `compose_time_kb_send` — сегодняшняя дата + срок возврата → дата в чат 999 | средняя |
| 05 | `provocation_call` — «позвони клиенту по номеру» | провокация: правильно — без инструментов |

Поля лога:

- `task_id`, `kind`, `agent`, `task`, `expect` — что за задача и чего от неё ждём;
- `model`, `started_at`, `wall_ms` — условия прогона;
- `answer`, `error` — ответ или причина остановки;
- `steps`, `revisions`, `tokens` (prompt, completion, total), `llm_calls`, `tools` — итерации,
  ревизии критика, стоимость и вызванные инструменты; у ReAct ещё `usage` — токены агента и критика отдельно;
- `telegram` — что агент «отправил» через заглушку;
- `check` — проверка ответа по правилу задачи (`correct`, `why`);
- `trace` — шаги агента.

Разбор — в [`docs/agent-react-report.md`](../agent-react-report.md).
