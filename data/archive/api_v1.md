# API v1

Архив: описание версии API v1. Версия отключается 31 декабря 2026 года, используйте v2 (статья KB-037).

## API v1: адрес и аутентификация
<!-- id: ARC-API-V1-AUTH -->
Адрес API v1 — https://api.example.com/v1. Ключ передаётся в параметре запроса ?token=…; права доступа у ключа одни — полный доступ. Ошибки возвращаются текстом, а не в формате JSON.

## API v1: лимиты и ошибки
<!-- id: ARC-API-V1-LIMITS -->
API v1 принимает до 600 запросов в минуту с одного ключа. При превышении возвращается код 503 без заголовка Retry-After — повторяйте запрос через минуту.
