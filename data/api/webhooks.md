# Вебхуки

Вебхуки настраиваются в «API-ключи» → «Вебхуки»: укажите URL и выберите события. Сервис отправляет POST-запрос с JSON и подписью в заголовке X-Signature. Если ваш сервер не ответил кодом 200, доставка повторяется 5 раз с растущей паузой.
