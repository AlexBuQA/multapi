Возвращает текущий статус компонента сервиса: работает штатно, работает с деградацией или недоступен — и описание инцидента, если он есть.
Используй, когда пользователь сообщает, что что-то не работает, не приходит или тормозит: не приходят письма, не удаётся войти, не проходит оплата, API отвечает ошибками.
Компоненты: auth — вход и авторизация; email — почтовые уведомления; billing — оплата; api — публичный API; mobile — мобильное приложение; all — все компоненты сразу.
